# Merek XyinnCht

## Pemeriksaan yang sudah dilakukan

- **Sapu kode:** tidak ada nama, warna hijau khas, atau teks aplikasi referensi di kode (`apps/`). 3 kecocokan hanyalah `import.meta.url`.
- Lencana centang biru: bentuk perisai sendiri, bukan bentuk lencana platform lain.
- Warna aksen indigo dan 7 tema bawaan adalah desain sendiri.

## Belum diperiksa (lakukan sendiri sebelum rilis publik)

- Ketersediaan nama "XyinnCht": cari di pencarian merek DJKI (pdki.dgip.go.id), Google Play, dan domain. Saya tidak bisa memastikan nama ini bebas.
- ID paket `com.xyinncht.app` di `app.json`: ganti bila Anda memakai domain sendiri.
- Ikon aplikasi dan logo: belum dibuat. Buat sendiri atau pakai alat desain; jangan memakai logo aplikasi lain.
- Email dukungan dan URL privasi/ketentuan di `app.json` masih contoh.
